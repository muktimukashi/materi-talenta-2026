Tipe Data Dasar

Tipe data memberi tahu jenis isi dari sebuah variabel.

🔤

String

Teks, ditulis memakai tanda petik.

let nama = "Sinta";
🔢

Number

Angka, tanpa tanda petik.

let umur = 12;
✅

Boolean

Nilai benar atau salah.

let hadir = true;
