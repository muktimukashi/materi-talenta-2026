Program Python Pertama

Buat file bernama main.py, lalu tulis:

print("Hello, World!")

Perintah print() digunakan untuk menampilkan teks ke layar.

Struktur Dasar Program

# komentar nama = "Alya" umur = 14 print(nama) print(umur)
  • Komentar diawali tanda #.
  • Variabel menyimpan data.
  • print() menampilkan hasil.

Aturan Sintaks Dasar

Case Sensitive

Nama dan nama dianggap berbeda.

Tanda Kutip

Teks ditulis dengan "..." atau '...'.

Indentasi

Jarak menjorok penting dalam Python.

Error Itu Normal

Error adalah bagian dari belajar debugging.

Latihan: Biodata Sederhana

print("Nama: Budi") print("Kelas: 9") print("Hobi: Bermain game") print("Cita-cita: Game Developer")

Ubah isi biodata sesuai data diri masing-masing.

Debugging Cepat

Error Umum

Lupa tanda kutip, salah tulis perintah, atau file belum disimpan.

Cara Memperbaiki

Baca pesan error, cek baris kode, perbaiki, lalu jalankan ulang.
