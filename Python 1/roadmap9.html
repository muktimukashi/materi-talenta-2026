Roadmap Kompetensi

Fondasi

Menjalankan program pertama, memahami sintaks Python, variabel, input, dan tipe data.

Kontrol Program

Menggunakan percabangan, perulangan, function, parameter, dan return.

Data & Modularitas

Mengelola list, dictionary, class, object, file, module, dan library eksternal.

Game Loop

Mengenal jendela game, objek, event, mekanisme utama, skor, level, dan musuh.

Quality

Melakukan testing, menemukan bug, memperbaiki kesalahan, dan mengoptimalkan program.

Publikasi

Menyusun dokumentasi, menjelaskan proses, mendemonstrasikan game, dan refleksi.

Contoh Aktivitas Awal

Hook

Guru menampilkan demo game sederhana lalu bertanya: “Bagaimana sebuah game mengetahui pemain menang, kalah, atau mendapat skor?”

player = input("Nama pemain: ") skor = 0 if player: print("Selamat datang,", player) skor += 10 print("Skor awal:", skor)

Pilihan Proyek Game

Snake

Latihan arah gerak, skor, collision, dan game over.

Pong

Latihan pantulan bola, kontrol pemain, dan sistem poin.

Maze

Latihan map, karakter, rintangan, dan tujuan permainan.

Platformer

Latihan gravitasi, lompatan, level, dan musuh.

RPG Mini

Latihan karakter, item, dialog, dan pertarungan sederhana.

Edu Game

Game kuis atau latihan pelajaran dengan skor dan feedback.
