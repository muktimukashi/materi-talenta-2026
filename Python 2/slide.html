Mengenal input()

input() digunakan untuk meminta pengguna mengetik jawaban.

nama = input("Siapa namamu? ")

print("Halo", nama)
Output contoh:
Siapa namamu? Rani
Halo Rani

Input Angka Perlu Diubah

Hasil input() selalu berupa teks. Untuk angka, gunakan int().

Tanpa int()

umur = input("Umur: ")

Umur disimpan sebagai teks.

Dengan int()

umur = int(input("Umur: "))

Umur disimpan sebagai angka.
