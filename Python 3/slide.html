Apa itu if?

if digunakan untuk membuat keputusan berdasarkan kondisi.

skor = 100

if skor >= 70:
    print("Lulus")
else:
    print("Belum lulus")
✅ Jika benar: Lulus
❌ Jika salah: Belum lulus

Explain

Struktur if

if kondisi:
perintah_jika_benar
else:
perintah_jika_salah

Perhatikan titik dua : dan indentasi.

Apa itu while?

while digunakan untuk mengulang selama kondisi masih benar.

nyawa = 3

while nyawa > 0:
    print("Main lagi")
    nyawa = nyawa - 1
Selama nyawa lebih dari 0, game masih berjalan.

for vs while

🔢

for

Dipakai ketika jumlah pengulangan sudah jelas.

for i in range(3):
    print(i)
⏳

while

Dipakai ketika pengulangan bergantung kondisi.

while jawaban != "stop":
    jawaban = input()

Challenge 2: Tebak Angka dengan Kesempatan

Tambahkan while

Pemain punya 3 kesempatan untuk menebak angka.

Nyawa berkurang setiap salah menjawab.
angka = 7
nyawa = 3

while nyawa > 0:
    tebak = int(input("Tebak: "))

    if tebak == angka:
        print("Menang!")
        break
    else:
        nyawa = nyawa - 1
        print("Sisa nyawa:", nyawa)
